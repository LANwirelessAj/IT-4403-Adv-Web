Task 2: Horizontal Slideshow

The infinite-scroll demo turned into a left-and-right slideshow with a (current / total) page counter.

(1 / 1)

Next loads another page when you reach the end. Arrow keys work too.

What I Changed

Horizontal slideshow. The original added each page under the last one as you scrolled down. Now every page of ten books is one slide, and the slides sit side by side in a flex row inside a window that hides the overflow. Previous and Next animate the row's margin-left by one slide width with jQuery .animate(), so results move left and right instead of up and down. The scroll listener is gone.

Paging display. The counter between the buttons shows (current page / total pages), for example (3 / 4). Total pages counts the pages loaded so far, the same way the instructor's vertical slideshow example counts them. When you're on the last loaded page, Next requests the following page, adds it as a new slide, and slides to it. Next turns off once Open Library has no more results.

Also changed. Each slide is rendered with a Mustache template, limit=10 fixes the same page-size gap as Task 1, and the left and right arrow keys move between slides.
