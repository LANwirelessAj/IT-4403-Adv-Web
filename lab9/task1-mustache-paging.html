Task 1: Paging with a Mustache Template

The instructor's paging demo rewritten so Mustache templates render the results, page links, and selected book.

Search to see results.

Click a cover to see its details.

What I Changed

Mustache templates. The original built every cover as a long string with + and stored the title, author, and year in data- attributes, which needed its own escapeHtml() function. Now three templates in the page hold all the HTML: one for the result covers, one for the page links, and one for the selected book. The JavaScript only prepares data and calls Mustache.render(), and Mustache escapes values by itself, so escapeHtml() is gone.

Paging fix. The original asked for &page=2 without a limit. Open Library's default page size is 100, so page 2 started at result 101 and skipped 90 books. Adding limit=10 makes each page exactly the next ten.

Smaller fixes. Only the pages that exist are shown (a search with 23 matches gets 3 page links, not 5), the current page is highlighted, and missing covers show the title instead of the old via.placeholder.com image, which no longer loads.
