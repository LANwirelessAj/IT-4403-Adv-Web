How weather.json Is Structured

Before coding, I opened the file in a JSON formatter. It's one object from the OpenWeatherMap API with these main sections:

Simple values
name (city), id, dt (time of reading), base, cod
Nested objects
coord (lon, lat), main (temp, pressure, humidity, min and max), wind (speed, deg), clouds (all), sys (country, sunrise, sunset)
Arrays
weather holds an array of condition objects, each with main, description, and icon

The raw values need converting before they mean anything to a reader. Temperatures come in Kelvin, wind speed in meters per second, wind direction in degrees, and every time is a Unix timestamp in seconds. The page converts all of them.
