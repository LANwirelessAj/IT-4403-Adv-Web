How the Three Methods Compare

fetch()
Built into the browser. A 404 does not reject the promise, so the code has to check response.ok before calling response.json().
$.ajax()
The full jQuery method. A 404 goes straight to .fail(), and options like timeout and dataType are set in one object.
$.getJSON()
A shortcut for $.ajax() with dataType: "json". Shortest to write, with fewer options.

The API's keys have spaces (post code, place name, state abbreviation), so dot notation won't work. The code uses bracket notation like place["place name"]. The places array is looped in full, since some ZIP codes cover more than one place. The ZIP is read as text so leading zeros like 02134 aren't lost.
