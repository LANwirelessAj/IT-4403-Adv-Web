    How It Builds on the Instructor's Example

    The instructor's demo searched with a fixed starting term and only showed cover images. Mine reads the user's term, asks for exactly the fields it needs with fields=key,title,author_name,first_publish_year,edition_count and limit=5, and lists each book's title, authors, first publication year, and edition count. author_name is an array, so the names are joined into one line. Any missing field shows "Not available" instead of breaking the page.
