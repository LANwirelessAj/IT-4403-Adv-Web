jQuery is a lightweight, "write less, do more", JavaScript library. The purpose of jQuery is to make it much easier to use JavaScript on your website. jQuery takes a lot of common tasks that require many lines of JavaScript code to accomplish, and wraps them into methods that you can call with a single line of code. jQuery also simplifies a lot of the complicated things from JavaScript, like AJAX calls and DOM manipulation.

What I Changed from the Starting Example

I kept the instructor's five buttons and the jQuery paragraph as the target, then built on top of it.

Fixed: The original file defines changeColor() and changeBorder(), but they call getRandomColorCode(), which doesn't exist in that file, and no buttons use them. I added the missing function and wired all three style functions to buttons. I also converted changeBorder() to jQuery's .css().

Added: Separate fade and slide controls (fadeOut, fadeIn, fadeToggle, fadeTo, slideUp, slideDown, slideToggle), a custom animate(), a chained sequence, a speed picker, and a reset button. Every effect calls .stop(true, true) first, so rapid clicking doesn't pile up a queue of animations.
