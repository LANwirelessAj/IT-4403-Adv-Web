How It Works

The odd rows are selected with $("#assets tbody tr:nth-child(odd)"). That counts from 1, so it picks rows 1, 3, 5, and 7. I used it over jQuery's older :odd filter because :odd counts from 0 (which actually selects rows 2, 4, and 6) and is deprecated in current jQuery.

Each body row gets a click handler with $(this).hide(), so only the row you click disappears. Restore calls .show() on every row.
