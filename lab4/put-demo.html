HTTP PUT Demo with jQuery AJAX

A working version of the instructor’s jsonplaceholder-addcomment.html example.

Request

This sends a PUT request to https://jsonplaceholder.typicode.com/posts/1 with jQuery’s $.ajax(), replacing post 1 with new values.

Response

Select the button to send the request. The response also prints to the browser Console.

JSONPlaceholder is a fake API, so it answers as if the update worked but nothing is actually saved. Loading post 1 again still returns the original data.

Changes from the instructor example

Fixed: The original requested http://. This site runs on HTTPS, so the browser blocks that request as mixed content and nothing happens. I switched it to https://.

Updated: jQuery 2.1.4 to 3.7.1 to match the rest of the site, and sent the data as JSON with a Content-Type header.

Added: The response now shows on the page with its HTTP status, not only in the Console, plus an error message if the request fails. The file was named “addcomment” but it updates a post with PUT, so the page is labeled to match what it does.
