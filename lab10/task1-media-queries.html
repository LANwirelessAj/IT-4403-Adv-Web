Task 1: Media Queries

The four required media query rules. Each card lights up when its query matches the current window.

Resize the window or open DevTools device mode (Ctrl + Shift + M). A card turns its rule's color when the CSS media query matches. The badge is a separate check using window.matchMedia() with the same query text, so the two always agree.

a

Screen width between 400px and 600px

Checking...
@media screen and (min-width: 400px) and (max-width: 600px) {
  #mq-a { border-color: #22c55e; background: #22c55e22; }
  #mq-a .mq-letter { background: #22c55e; }
}

Both ends are inclusive, so exactly 400px and 600px count.

b

Portrait orientation and width under 640px

Checking...
@media (orientation: portrait) and (max-width: 639px) {
  #mq-b { border-color: #a855f7; background: #a855f722; }
  #mq-b .mq-letter { background: #a855f7; }
}

Portrait means the viewport is taller than it is wide. max-width: 639px keeps it strictly under 640px.

c

Narrower than 16:9 and width 480px to 960px

Checking...
@media (max-aspect-ratio: 16/9) and (min-width: 480px) and (max-width: 960px) {
  #mq-c { border-color: #f97316; background: #f9731622; }
  #mq-c .mq-letter { background: #f97316; }
}

max-aspect-ratio: 16/9 matches any shape whose width-to-height ratio is 16:9 or less, so a 4:3 window matches and a wide 21:9 window doesn't.

d

Same styles for print and screens under 480px

Checking...
@media print, screen and (max-width: 479px) {
  #mq-d { border-color: #ef4444; background: #ef444422; }
  #mq-d .mq-letter { background: #ef4444; }
}

The comma works like OR. The styles apply when the page is printed, or on a screen narrower than 480px. Open the print preview (Ctrl + P) to see the print side.
