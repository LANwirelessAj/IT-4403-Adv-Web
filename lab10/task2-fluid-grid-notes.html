Task 2: Fluid Grid Layout

lab10a-fixed.html converted from fixed pixel widths to percentages.

The Converted Page

Open lab10a-fluid.html and resize the window. The original lab10a-fixed.html stays 900px wide no matter what, so it scrolls sideways on a phone and leaves big empty margins on a wide monitor.

px to % Conversions

The fluid grid formula is target ÷ context = result. The context is the 900px container every column lived in.

ElementFixedMathFluid
#container width900pxSet relative to the window90% (max 1200px)
#sidebar width200px200 ÷ 90022.2222%
#main margin-left210px210 ÷ 90023.3333%

Two supporting changes keep it from breaking: box-sizing: border-box so the 2px borders stay inside each percentage, and clear: both on the footer so it never slides up beside a tall sidebar. I also added the viewport meta tag, which a phone needs before it'll render the page at its real width.
