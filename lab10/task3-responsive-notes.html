Task 3: Full Responsive Design

lab10b-fixed.html rebuilt with a fluid grid and media queries for desktop, tablet, and mobile.

The Responsive Page

Open lab10b-responsive.html and resize it, or use DevTools device mode (Ctrl + Shift + M). Compare it with the original lab10b-fixed.html, which is locked at 1000px.

What Changed

Fluid grid. The container went from 1000px to 95% (max 1200px). The sidebar is 20% (200 ÷ 1000), the main area's margin is 22% (220 ÷ 1000), and each product is 23% with 1% margins so four fit in a row. box-sizing: border-box keeps the borders and padding inside those percentages.

Media queries. At 900px the products drop to three per row so the text doesn't get cramped. At 600px the sidebar stops floating and moves above the content, since a 20% column on a phone is too narrow to read, and the products go to two per row. At 400px each product takes the full width.

Readability. Products use min-height instead of a fixed 200px height, so longer text grows the box instead of spilling out. The viewport meta tag is added so phones render at their real width.

Header image. The original header pointed to an http:// image on ksuowls.com. Browsers block http images on an https site, and that link no longer loads, so I replaced it with a text header in KSU black and gold. Any image added later is covered by img { max-width: 100%; }.
