What I Changed

Button text. All three buttons now read "Load Updated Content."

New success content. When a request succeeds, a green confirmation appears under the response showing which jQuery method ran, the time it loaded, and how many times that section has been updated. The page load counter at the top of this section proves the page itself never reloaded.

Response heading. Each response area has an "AJAX Response" heading above it.

Error handling. The original had none. If the PHP page can't be reached, each section now shows an error message instead of silently doing nothing.

The server page is the instructor's ajax-dynamic-response.php, unchanged. View the original example

Questions to Consider

1. Which jQuery AJAX method is used? The example uses three: .load(), which requests HTML and drops it straight into the selected element; $.get(), which sends a GET request and hands the response to a callback; and $.ajax(), the general method the other two are built on, with options like data for parameters.

2. What part of the page changes? Only the response div under the button that was clicked. The heading, buttons, and the other two sections stay exactly as they were.

3. Why does AJAX update without a full reload? The request is sent in the background by JavaScript instead of by the browser navigating to a new URL. When the response comes back, jQuery inserts it into one element in the existing DOM. The browser never throws away the current page, so nothing else has to be rebuilt.
