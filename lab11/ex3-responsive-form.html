From Basic HTML to Bootstrap

The basic form I started from

<form>
  <p>Name: <input type="text" name="name"></p>
  <p>Email: <input type="email" name="email"></p>
  <p>Book title: <input type="text" name="title"></p>
  <p>Format:
    <select name="format">
      <option>Hardcover</option><option>Paperback</option><option>E-book</option>
    </select>
  </p>
  <p>Notes:<br><textarea name="notes"></textarea></p>
  <p><input type="submit" value="Send"></p>
</form>

What changed

  • Each field got a real <label> with form-label, tied to its input by for and id.
  • Inputs and the textarea use form-control, and the dropdown uses form-select, so they're full width and sized the same.
  • The fields sit in a row g-3 grid. Name and email share a row from md up (col-md-6), title and format split 8 and 4, and everything stacks on phones.
  • g-3 handles the spacing between fields, and gap-2 spaces the buttons.
  • Bootstrap's validation styles flag empty or invalid fields with a message under each one instead of the browser's default popups.
