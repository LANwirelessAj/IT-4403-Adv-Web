Exercise 1a: Five Grid Layouts

Breakpoint: xs (<576px)sm (576px+)md (768px+)lg (992px+)xl (1200px+)

Five layouts built with Bootstrap rows and columns. Resize the window and watch the breakpoint badge: each layout rearranges at the sizes noted in its description.

Layout 1: Equal columns

Three .col columns split the row evenly at every size. Bootstrap divides the width by however many columns there are.

</div>

Layout 2: Main content with sidebar

An 8 and 4 split from the md breakpoint up. Below 768px both columns go full width and stack.

.col-md-8 (main)
.col-md-4 (sidebar)
Show the markup

  <div class="col-md-8">...</div>
  <div class="col-md-4">...</div>
</div>

Layout 4: Centered column with offset

col-md-6 offset-md-3 pushes a half-width column three units in, centering it. The second row centers two columns with justify-content-center instead.

.col-md-6 .offset-md-3
.col-sm-4
.col-sm-4
Show the markup
<div class="row g-3">
  <div class="col-md-6 offset-md-3">...</div>
</div>
<div class="row g-3 mt-0 justify-content-center">
  <div class="col-sm-4">...</div>
  <div class="col-sm-4">...</div>

Layout 5: Nested grid with auto-width column

The left column holds a row of its own, a nested grid. On the right, col-auto sizes itself to its content and the col beside it takes the rest.

.col-6 (nested)
.col-6 (nested)
.col-auto
