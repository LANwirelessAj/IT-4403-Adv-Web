Exercise 1: Flexbox Item Layouts

The four playground layouts, rebuilt with flexbox. Every value is editable, just like CodePen.

How This Works

These are the four item layouts from the lab, rebuilt with plain CSS flexbox. Like a CodePen or flexbox playground, each item's values are live: change order, flex-grow, flex-shrink, flex-basis, or align-self and the layout updates immediately. The × removes an item, and Reset puts the layout back.

Layout 1: Centered column

flex-direction: column with align-items: center. Every item keeps the defaults (grow 0, shrink 1, basis auto), so they stack at a fixed width in the middle.

.container { display: flex; flex-direction:column; align-items:center; }
.item      { width: 72%; }
.item-1 { order: 0; flex: 0 1 auto; }
.item-2 { order: 0; flex: 0 1 auto; }
.item-3 { order: 0; flex: 0 1 auto; }

Layout 2: Three equal columns

flex-wrap: wrap with every item set to flex-grow: 1. Each item starts at 30% and grows to share the leftover space equally, so the six items fill two rows of three.

Layout 3: Wide first item

Item 1 uses flex-basis: 73% with flex-shrink: 0 so it can't be squeezed. Item 2 takes what's left on that row, and the next four wrap to a row of their own.

Layout 4: Full-width first and last

Items 1 and 5 use flex-basis: 100%, so each takes a whole row. Items 2 to 4 share the middle row, and item 3's flex-grow: 4 gives it four shares of the leftover space to the others' one.
